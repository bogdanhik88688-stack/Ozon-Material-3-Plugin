# Ozon Material 3 Expressive (`v1.0.0`)

Кроссбраузерное расширение (Manifest V3) для полного редизайна сайта **Ozon** (`ozon.ru`, `ozon.by`, `ozon.kz`) в стиле **Material Design 3 Expressive**.

## Возможности

- **Полный редизайн в Material Design 3 Expressive и заливка акцентом:** гармоничные тона выбранного акцента, поддержка светлой, тёмной, AMOLED и авто-темы.
- **Подложки под цены товаров:** тональные MD3-бейджи с градиентом акцента вокруг актуальной цены.
- **RGB-настройка цветов в стиле MD3:** Expressive-ползунки `R / G / B` (0–255) с HEX-полем отдельно для акцента, текста и кнопок.
- **Кнопка «Параметры» с автоскрытием при скролле:** скрывается при прокрутке вниз и появляется при скролле вверх.
- **Полное удаление рекламы и баннеров:** сетевой фильтр `declarativeNetRequest` + умный DOM-блокировщик рекламы и спонсорских карточек (`erid=`).
- **Гибкая кастомизация:** скругление углов (`0px–36px`), размеры кнопок, текста и иконок, плотность карточек, Spring-анимации и переходы страниц.
- **Иконки Material Symbols Rounded:** обновлённые иконки корзины, избранного, заказов, каталога, поиска и навигации.

## Установка

### Chrome, Edge, Яндекс Браузер, Opera, Brave, Vivaldi, Arc
1. Скачайте `ozon-md3-expressive-chromium.zip` из раздела **Releases** (или распакуйте репозиторий).
2. Откройте страницу расширений (`chrome://extensions`, `edge://extensions`, `browser://extensions`).
3. Включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**, выбрав папку с `manifest.json`.

### Mozilla Firefox (115+)
1. Скачайте `ozon-md3-expressive-firefox.zip` из раздела **Releases** (или соберите через `build-packages.ps1`).
2. Откройте `about:debugging#/runtime/this-firefox` → **Загрузить временное дополнение…** → выберите `manifest.json` или архив.
